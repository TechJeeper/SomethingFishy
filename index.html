Flash from the browser

Enter Wi‑Fi and your OpenAI API key, then program the ESP32 over USB with Web Serial — no Arduino IDE required.

What you’ll build

A wall-mounted AI with gills

SomethingFishy bypasses Billy’s original microcontroller — snip the motor and speaker leads at the old board, leave the fish mechanisms alone, and drive them from an ESP32-S3 with an I2S mic, amp, and L298N. Almost no soldering.

Build path

Four stages

  1. Parts & prep — Order the BOM, gather tools, print the optional backplate.
  2. Bypass the stock board — Snip motor + speaker wires at the PCB; leave mechanisms mounted.
  3. Wire the brain — Dupont jumpers + lever nuts / screw terminals to ESP32, mic, amp, L298N.
  4. Flash & talk — Configure OpenAI + Wi‑Fi on the flash page, then say hello.
