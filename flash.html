Web Serial programmer

Flash Billy

Enter Wi‑Fi and your OpenAI API key, connect the ESP32-S3 over USB, and program it from this page. Credentials are packed into a config partition on-device — they are not uploaded to any server.

Browser required

Web Serial works in Chrome or Edge on desktop. The site must be served over HTTPS (GitHub Pages) or localhost.

1 · Device settings

Stored only in browser memory and written to the ESP32 config partition.
